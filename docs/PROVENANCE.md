# Provenance

Logging Stats adapts the collection, historical reporting, Parquet storage,
and static-site approach of **Russell Spitzer's Iceberg Community Health**:

https://github.com/RussellSpitzer/iceberg-community-health

Reference revision: `5e26873783da1849343a7c3dd0403f9ef56240d4`.

The UTC calendar helpers derive from that revision. Other modules implement
the Apache Logging specification with separate Issues and Discussions models.
Modified and new files use Apache-2.0. Preserve the upstream LICENSE and NOTICE.
The inherited NOTICE also credits Patrick McFadin's community-health work.
The upstream Apache Magpie submodule is not included or required here.

No Iceberg dataset or rendered dashboard is included.

This is an independent project. It does not claim ASF endorsement.
